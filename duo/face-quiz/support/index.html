Getting started

Create a deck, add cards and Save before studying. CSV imports use two nonempty columns (front and back), with optional front/back header; limit 2 MB and 2,000 cards per deck. Import adds cards to the editor; Save commits them. Editing a card resets its grading history. Use Restore for a prior deck-limit purchase.
