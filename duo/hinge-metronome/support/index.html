Getting started

Choose 30–300 BPM, the beat count and a click sound, then start the metronome. Lock the tempo to keep it stable. Use the slider on a non-folding phone. The tuner needs microphone permission; stop it or revoke permission when finished. A chosen file provider may download a score. Use the score trash button to delete it.
