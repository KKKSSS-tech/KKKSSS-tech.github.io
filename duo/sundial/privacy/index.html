App data

Coordinates, location accuracy, true heading, gravity, available fold state and current time are processed in memory for the sundial. Sensor history is not saved or uploaded. Backgrounding clears samples. The app has no ads, accounts, analytics or in-app purchases.

There is no advertising SDK. The developer does not collect personal data through the app.

An exported PNG leaves the app only through your chosen sharing destination. It may reveal the shadow and time shown. Delete exported copies with that provider. You can revoke location permission in system settings; without usable location or heading the calculation is unavailable.

Storage and deletion

The app does not save sensor history. Remove the app to delete any app-local settings. Manage exported PNGs, device backups and provider records separately.

Public pages and support

These pages use GitHub Pages. We add no analytics or external fonts; the host may process access information such as IP addresses. See GitHub's Privacy Statement.

If you email support, your reply address and message are used to handle the inquiry. Do not send passwords, payment details or unnecessary personal information. Contact kkksss.support@icloud.com for support, privacy questions or requests about inquiry information, including deletion.

Changes to data handling will be reflected on this page with an updated date.
