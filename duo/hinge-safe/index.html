VaultDial

Fold-angle combination puzzle

OverviewPrivacySupport

Dial a safe with the fold angle, one step of the game combination at a time.

VaultDial is an offline puzzle that uses a rotary dial displayed on the screen. It features 50 stages where difficulty changes through angle tolerance and sequence length. An optional time limit can be set. Players can create custom sequences for friends and share them with a link or QR code. All modes work with an on‑screen rotary dial on ordinary phones, offering haptic feedback and a visible proximity hint. Purchase is one‑time only: ¥400 / $2.99. No ads, no subscription, no account, and no online multiplayer. Friend links require VaultDial installed and contain only game sequences.

Requires iOS 17 or later. Visible hints keep the puzzle playable when haptics are unavailable.
