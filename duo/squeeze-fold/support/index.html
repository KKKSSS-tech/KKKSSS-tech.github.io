Sound Sketchbook — eight-bar editor

Basic editing, six chord pads, percussion and saving are free. Full Bellows adds the Dusk and Drift progressions and the B-flat-major and D-major chord pads. Tap the Full Bellows button to open purchase and restore. The purchase button shows the localized price supplied by StoreKit.

Start with “Place one chord to begin”, then choose Percussion to add a hit. Both sounds belong to the same eight-bar song. Tap Listen to hear them together. Choose a bar and step to edit an existing note. Chord length, Earlier and Later change the selected event; Remove note removes only that layer’s selected note. Notes added while listening are heard on the next playback.

Save song keeps a named sketch in Songs. New eight-bar sketch saves the current nonempty song before starting another. If a write fails, your notes remain in the editor: use Retry save before opening another song or leaving the app. Unsaved edits held only in memory may be lost if the app is terminated.

If the app says the saved file is protected, it has refused to replace that file. Reopen the app to retry reading. There is no reset command. Keep the app and its data while requesting help; removing the app can remove local songs.

Audio interruptions stop playback. Tap Listen when ready to start again. The playback volume control includes a visible muted state.

For help, contact kkksss.support@icloud.com with Sound Sketchbook, the app and system versions, what you were doing and the message shown. Do not send passwords, payment details or private compositions unless you choose to share them.

Earlier Squeezefold — bellows instrument

The following previously published description is retained for the earlier instrument interface. It does not describe the Sound Sketchbook editor.

Getting started

Choose a progression and voicing, then sustain a chord. On a non-folding phone use horizontal swipes or buttons. Home is free; the other progressions support an optional temporary rewarded trial or a purchase when available. Pause before leaving. Use the explicit reset if the app reports unreadable saved settings.
